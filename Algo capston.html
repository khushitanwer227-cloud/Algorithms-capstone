ExamColor

Automatic exam timetable generator. Subjects are vertices, shared students are edges, and an exam slot is a colour. Backtracking finds the minimum number of slots with no student clash.

How it works

Order vertices by degree (most constrained first). For k = 1, 2, 3 … try to colour every vertex using ≤ k colours: give a subject the first slot not used by an already-scheduled neighbour; if none fits, backtrack. The first k that works is the minimum number of slots (chromatic number). Pruning: a vertex may only open one new colour at a time (removes symmetric solutions). Worst case O(kⁿ) time, O(n) space; Welsh–Powell greedy is O(n²) but may use more slots.
